# Description:

 This is the frontend part of the Milk Fat Content Checker web application. It is built using React and TypeScript. The frontend communicates with the backend to send user input and receive predictions about the fat content of milk.

# Technologies Used:
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- Chart.js

# Installation:

1. Install the dependencies:
```bash
npm install
```

2. Set the values of the environment variables in the `.env` file. You can use the `.env.example` file as a template.


3. Start the development server:
```bash
npm run dev
```
